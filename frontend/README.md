# Week 1 React frontend skeleton

Plain React + Vite + JavaScript JSX + Tailwind 4 scaffold, with empty folders/files for auth, admin, owner, and shared UI. No API logic, business logic, mock implementation, or completed screens.

## Windows setup

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Install shadcn/ui components later using its CLI after configuring project aliases. The `components/ui` folder is reserved but no generated shadcn components are included.

Week 1: frontend screens ready; full backend integration in Week 2.
